# Contributing Guide

## 🏁 Setup

```bash
# Make sure you have Node 18+
node --version

# Install dependencies
pnpm install

# Run the app
pnpm dev
```

Open http://localhost:3000 — you should see a 3D canvas.

---

## 🔄 Workflow

```bash
# Create your branch
git checkout -b onboarding/your-name

# Make changes, then commit
git add .
git commit -m "add warehouse buildings"

# Push when ready
git push origin onboarding/your-name
```

---

## 📝 Commit Messages

Keep them simple and descriptive:

```
add cargo building models
fix camera controls
update lighting
```

---

## ✅ Before Submitting

- [ ] App runs without errors
- [ ] Looks good in the browser
- [ ] Added a screenshot or video to your PR
